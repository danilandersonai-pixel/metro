# Тоннели (рабочее название)

Пошаговая стратегия о выживании в метро: глобальная карта + бои шеренгами.
Подробный дизайн и правила разработки — в [CLAUDE.md](CLAUDE.md).

```
npm install     # установка
npm run dev     # запуск в браузере
npm test        # тесты логики
npm run build   # сборка
```
