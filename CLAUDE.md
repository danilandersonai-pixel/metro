# CLAUDE.md — «Тоннели» (рабочее название)

Пошаговая стратегия про выживание в метро после катастрофы. Механически повторяет
мобильную игру Metro 2033 Wars / Moscow Metro Wars (DaSuppaStudios, 2014):
**глобальная карта как в Total War + пошаговые бои шеренгами как в Disciples/Heroes**.

> Важно про права: механики (правила, формулы, структура игры) повторять можно.
> Нельзя копировать чужие тексты, сюжет, названия фракций и персонажей из книг
> Глуховского, графику, звук и логотипы оригинальной игры. Поэтому сеттинг, фракции,
> квесты и все тексты в этом проекте — **собственные**. Названия реальных станций
> московского метро как географию использовать можно.

## 0. Как работать с этим проектом (для Claude Code)

- Всегда отвечай и пиши комментарии в коде **на русском**. Идентификаторы — на английском.
- Владелец проекта — начинающий разработчик. После каждого шага коротко объясняй,
  что сделано и как это проверить (какую команду запустить, что увидеть в браузере).
- Работай **этапами** из раздела 9. Не переходи к следующему этапу, пока текущий
  не запускается и не проходит тесты. В конце этапа — коммит в git.
- Перед крупным изменением кратко опиши план (3–6 пунктов), потом делай.
- Вся игровая логика — **чистый TypeScript без зависимости от Phaser** (папка `src/core`).
  Phaser только рисует и передаёт ввод. Так логику можно тестировать без браузера.
- Все игровые числа (урон, цены, доход) — только в JSON-файлах `src/data/`.
  Никаких «магических чисел» в коде.
- Случайность — только через сидируемый генератор `core/rng.ts`, чтобы бои
  воспроизводились в тестах.
- Не добавляй библиотеки сверх раздела 2 без явной просьбы владельца.

Команды:
```
npm install        # установка
npm run dev        # запуск в браузере (Vite)
npm test           # тесты логики (Vitest)
npm run build      # сборка
npx cap sync android   # (этап 8) перенос сборки в Android-проект
```

## 2. Стек

- **TypeScript** (strict), **Vite** — сборка и dev-сервер
- **Phaser 3** — отрисовка карты, боя, анимации, ввод
- **Vitest** — тесты логики
- **Capacitor** — упаковка в Android/iOS (этап 8)
- Графика на старте — простые фигуры и плейсхолдеры, потом свои спрайты.

Структура:
```
src/

    economy/            # ресурсы, доход, содержание, здания
    battle/             # пошаговый бой

    factions/           # фракции, дипломатия, торговля, ИИ
    quests/             # квесты, флаги сюжета, концовки
    turn.ts             # конец хода: порядок всех фаз
```

## 3. Основная концепция

Игра состоит из **двух неравных половин**:

1. **Глобальная карта** — плоская схема метро. Каждая станция — отдельная «клетка»
   (узел графа). Игрок водит отряды по тоннелям, захватывает станции, строит,
   торгует, ведёт дипломатию, выполняет квесты.
2. **Тактический бой** — отдельный экран-арена. Запускается, когда отряд
   входит на вражескую станцию, встречает вражеский отряд или мутантов.

Цель: двигаясь по сюжету и выполняя квесты, через цепочку сражений прийти к одной
из нескольких концовок. Мир открытый, но часть станций открывается по ходу сюжета.

Игровой цикл одного хода:
```
Игрок: двигает отряды → бои → управляет станциями → дипломатия/торговля → «Конец хода»
Система: доход → содержание → стройка → события (атаки мутантов) → ходы ИИ → проверка квестов
```

## 4. Глобальная карта

### 4.1 Данные
- `Station { id, name, lineIds[], x, y, ownerFactionId | null, unlocked, buildings[], garrison: Unit[], population, defenseBonus, tags[] }`
  - теги: `"hub"` (пересадка), `"surface_exit"` (выход наверх), `"abandoned"`, `"infested"` (логово мутантов)
- `Tunnel { from, to, length (в ходах), danger (0–3), blocked }`
- Линии метро — цвет и порядок станций; пересадки — отдельные тоннели длиной 1.

### 4.2 Отряды на карте
- `Squad { id, factionId, units: Unit[] (до 6), stationId | tunnelPos, movePoints }`
- Очки движения: 2 за ход (из `balance.json`). Тоннель длины N стоит N очков.
- Если в тоннеле `danger > 0` — при проходе бросок на случайное событие
  (засада мутантов → бой).
- Стоянка на своей станции — отряд лечится (+25% от макс. здоровья за ход).

### 4.3 Захват (как в Total War)
- Отряд входит на станцию:
  - своя/союзная → просто встаёт;
  - нейтральная пустая → захват сразу;
  - с гарнизоном врага → бой; победа = станция переходит игроку,
    часть зданий может быть повреждена (из `balance.json`);
  - нейтральная с жителями → можно захватить силой (минус отношения у всех)
    или договориться (через диалог/квест).
- Захват станции фракции, с которой мир, = объявление войны (с предупреждением).

### 4.4 Туман и открытие
- Видны станции на 1 тоннель от своих; дальше — «неизвестно».
- `unlocked=false` — станция закрыта, пока квест не снимет флаг.

## 5. Экономика и станции

### 5.1 Ресурсы (`resources.json`)
| id | Название | Источник | Тратится на |
|---|---|---|---|
| `ammo` | Патроны (валюта) | налоги со станций, торговля, трофеи | найм, стройка, торговля |
| `food` | Еда (грибы, свиньи) | фермы | содержание населения и бойцов |
| `fuel` | Топливо | склады, торговля | генераторы, дрезины |
| `power` | Энергия | генераторы | работа зданий |
| `meds` | Медикаменты | сталкеры, торговля | лечение, воскрешение |
| `scrap` | Хлам/материалы | сталкеры, разбор | стройка, ремонт |

Правило: «хорошая экономика позволяет держать несколько отрядов» — каждый боец
стоит `food` и `ammo` в ход. Отрицательный баланс → боевой дух падает, затем
бойцы дезертируют.

### 5.2 Здания (`buildings.json`), цель — около 20 типов
Каждое: `{ id, name, kind: "economy"|"military"|"special", cost{}, buildTurns, upkeep{}, effects[], requires[], maxLevel }`.

Экономические: Грибная ферма, Свиноферма, Генератор, Топливный склад, Рынок,
Мастерская (scrap→ammo), Лазарет, Казарма жилая (+население), Пост сталкеров
(только на `surface_exit`, даёт meds/scrap/fuel с риском потерь).

Военные: Блокпост (+оборона), Пулемётное гнездо (бьёт в начале боя), Баррикада
(снижает урон первому ряду), Оружейная (доступ к лучшим бойцам), Учебный лагерь
(+опыт гарнизону), Вербовочный пункт (найм на этой станции), Сигнальная система
(предупреждение об атаке, видимость +1).

Особые: Радиоточка (дипломатия +), Библиотека/архив (квесты), Церковь/клуб (+боевой дух).

### 5.3 Экран станции (`StationScene`)
- Список зданий и стройка (очередь, 1 стройка одновременно на станцию).
- Найм бойцов (если есть Вербовочный пункт / тип доступен фракции).
- Перевод бойцов между отрядом на станции и гарнизоном (drag&drop).
- Торговля, если станция торговая и с владельцем мир.

## 6. Бойцы и прокачка

### 6.1 Юнит (`units.json`, цель — ~25 типов)
```
UnitType { id, name, role, hp, armor, damage, accuracy, initiative,
           attackType: "melee"|"ranged"|"area"|"support",
           abilities[], passives[], cost{}, upkeep{}, factionTags[] }
Unit { uid, typeId, level, xp, hp, effects[], position: {row, slot} }
```
Роли (примеры своих типов): Штурмовик, Стрелок, Снайпер, Пулемётчик, Огнемётчик,
Медик, Инженер (чинит/ставит укрытие, баффы), Разведчик, Сталкер, Командир
(аура), Гранатомётчик; мутанты — отдельные типы врагов.

### 6.2 Опыт
- За бой: опыт делится между выжившими, бонус за добивание.
- Уровни 1–20, кривая в `balance.json` (`xpToLevel = 100 * level^1.5`).
- С уровнем: + к характеристикам и в определённые уровни новая атака,
  бафф или пассивка (таблица `levelUnlocks` у типа юнита).

### 6.3 Наёмники (платная функция оригинала)
- Особые элитные юниты, которые **не умирают насовсем** — после поражения
  выходят из строя на N ходов. У нас — награда за квесты, без доната.

## 7. Тактический бой (`core/battle`) — сердце игры

### 7.1 Поле
- Две стороны. У каждой **2 шеренги (передняя/задняя) × 3 позиции** = 6 мест на отряд.
- Бой может быть до **12 на 12**: к основному отряду добавляются «призванные
  на один бой» — гарнизон станции или союзники. Тогда у стороны 2 шеренги × 6
  позиций (или 4 шеренги × 3 — выбрать одно и зафиксировать в `balance.json`).

### 7.2 Очерёдность
- Порядок хода — по **инициативе** (больше — раньше), ничья — бросок `rng`.
- Раунд = каждый живой боец ходит один раз. Эффекты тикают в начале хода бойца.

### 7.3 Действие бойца (одно за ход)
- **Атака**:
  - `melee` — только по передней шеренге врага; бить заднюю можно, лишь если
    передняя пуста. Сам ближник атакует только из передней шеренги.
  - `ranged` — по любому врагу, откуда угодно.
  - `area` — по всей шеренге или по всем.
  - `support` — лечение/бафф своих.
- **Перемещение**: боец может перейти в соседнюю шеренгу, **если там свободная позиция**
  (ключевое отличие от Disciples — бойцы не прикованы к месту).
- **Способность** (если есть и не на перезарядке).
- **Защита** — до своего следующего хода получаемый урон −50%.
- **Ожидание** — переместиться в конец очереди раунда (1 раз за раунд).

### 7.4 Формулы (в `balance.json`)
```
шанс попадания = clamp(accuracy - targetEvasion + modifiers, 5%, 95%)
урон = damage * random(0.85..1.15) * (1 - armor/(armor+50)) * множители эффектов
крит: 10% базово, ×1.5
```

### 7.5 Эффекты
`bleeding`, `burning`, `stunned`, `poisoned`, `inspired`, `covered` (укрытие),
`suppressed` (−точность). Каждый: `{ id, turns, stacks, onTick, modifiers }`.

### 7.6 Конец боя
- Победа — у врага нет живых бойцов, или враг отступил.
- Отступление: доступно с 2-го раунда, отряд уходит на соседнюю свою станцию,
  каждый боец с шансом получает урон.
- Погибшие бойцы удаляются (кроме наёмников). Трофеи: `ammo`, иногда `meds`/`scrap`.
- Автобой: кнопка, где оба отряда ходят ИИ (обязательно для проверки баланса).

### 7.7 ИИ в бою (простой, предсказуемый)
1. Есть цель, которую можно убить этим ходом → бить её.
2. Медик и союзник ниже 40% HP → лечить.
3. Иначе бить цель с наименьшим `hp/maxHp`, приоритет — стрелки и медики.
4. Ближник в задней шеренге при свободном месте впереди → шагнуть вперёд.

## 8. Фракции, дипломатия, квесты

### 8.1 Фракции (`factions.json`, цель — ~24, из них ~12 торговых)
`{ id, name, color, ideology, startStations[], unitPool[], canTrade, aiPersonality }`
Названия и идеологии — **свои** (например: Торговый союз Кольца, Коммуна
Красносельской, Орден Последнего поезда, Вольные сталкеры, Культ Глубины,
дикие станции, мутанты — отдельная «фракция» без дипломатии).

### 8.2 Отношения
- Число от −100 до +100 у каждой пары фракций. Статусы: Война (< −50),
  Нейтралитет, Мир (> 20), Союз (> 70, только через квест/договор).
- Меняется от: захватов, выполненных поручений, подарков (`ammo`),
  торговли, нарушения договоров.
- Действия: предложить мир, торговый договор, союз, потребовать дань, объявить войну.

### 8.3 Торговля
- Только с торговыми фракциями при статусе ≥ Нейтралитет.
- Цены на станции зависят от запасов и отношений (`priceMod = 1 - relation/400`).

### 8.4 ИИ фракций (на глобальной карте)
Раз в ход для каждой фракции: оценка угроз → оборона/найм → стройка по приоритету
личности (агрессор/торговец/изолянт) → атака слабой соседней станции врага при
перевесе сил ×1.3.

### 8.5 События
- Атаки мутантов на станции у `infested` или `surface_exit` — случайно,
  шанс растёт со временем (оригинал: «отражать атаки мутантов»).
- События — данные в `events.json`: `{ id, trigger, chance, choices[] }`.

### 8.6 Квесты и сюжет
- Квесты — основа игры (в оригинале текст сюжета ~500 страниц, 70+ миссий).
- Формат `quests.json`:
```
Quest { id, title, giverStationId, requires: {flags[], relation{}},
        stages: [{ text, objective: {type, params}, onComplete: {setFlags, rewards, unlockStations} }],
        branches?: [{ choiceText, nextQuestId, setFlags }] }
```
- Типы целей: дойти до станции, захватить, победить отряд, доставить ресурс,
  довести отношения, построить здание, продержаться N ходов.
- Глобальные флаги сюжета ведут к **нескольким концовкам** (`endings` в `quests.json`).
- Обучение — первые 3–4 квеста учат: движению по тоннелям, сбору отряда, атаке,
  развитию станции (как в оригинале).

## 9. Этапы разработки (идти строго по порядку)

1. **Каркас**: Vite + TS + Phaser + Vitest, пустые сцены, `rng.ts`, `types.ts`. Проверка: `npm run dev` показывает меню.
2. **Бой без графики**: `core/battle` + тесты (очерёдность, правила ближнего боя, перемещение между шеренгами, эффекты, победа). Автобой 6×6 в тесте.
3. **Экран боя**: `BattleScene` — прямоугольники бойцов, полоски HP, очередь ходов, кнопки действий, лог боя.
4. **Карта**: 1 линия, 12 станций, 3 фракции, движение отряда, захват, бой при входе.
5. **Экономика и станции**: ресурсы, 8 зданий, найм, гарнизон, конец хода, содержание.
6. **Опыт, ИИ фракций, дипломатия, торговля, события мутантов**.
7. **Квесты**: обучение + короткая сюжетная цепочка с 2 концовками. **Сохранения** с версией.
8. **Мобильная версия**: адаптивный UI под касания, Capacitor → Android APK.
9. **Рост контента** до масштаба оригинала: все линии, ~190 станций, 24 фракции, 25 типов бойцов, 20 зданий, 70+ квестов.

Критерий готовности каждого этапа: `npm test` зелёный, `npm run dev` запускается,
владелец может пройти новый функционал руками по короткой инструкции от Claude.

## 10. Если нужен именно Unity (как в оригинале)

Вариант для тех, кто готов ставить Unity Editor:
- Unity 6 LTS, C#, вся логика — в обычных C#-классах (не MonoBehaviour), тесты через Unity Test Framework.
- Данные — ScriptableObject или JSON в `StreamingAssets`.
- Сцены и префабы собирает человек в редакторе; Claude Code пишет скрипты и данные.
Структура `core/` и правила разделов 3–8 остаются теми же.
